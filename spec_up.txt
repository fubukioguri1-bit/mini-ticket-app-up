現在のPythonソースコード（既存リポジトリの内容）と、人間が更新した仕様書（SPEC.md）の git diff を渡します。
SPEC.md の変更内容（diff）を既存のPythonコードに正確に反映させるための、修正計画と更新後のソースコードを作成してください。

【ルール】
・SPEC.md の変更点に関係ない既存の処理やインターフェースは壊さないこと
・まず「どのファイルのどこを修正するか（Plan）」を整理してから、修正後のコード全体を出力
・ソースコードの修正に合わせて、テストコード（tests/）とドキュメント類も新しい SPEC.md に整合するようにあわせて更新計画に入れる

【SPEC.md の git diff】
添付するspec_diff.txt

【現在のPythonソースコード】
添付するtxtファイル、htmlファイル
